## 一句话

市场分牛市、震荡、熊市三种。哪怕是牛市，也不是一根柱子直冲上去，而是涨、跌、涨、跌，只是涨的比跌的多。所以分两步：**第一步，判断现在是哪种行情；第二步，每次回调就买入，赚一点就卖，然后等下一次机会。**

## 交易规则（v1，已确认）

| 行情 | 开仓 | 止盈 | 止损 |
|---|---|---|---|
| 牛市 | **做多**：出现 1B/2B/3B（沿用 Project 1），信号当天按收盘价买入 | 买入价 × 1.015 | 买入价 × 0.95 |
| 震荡 | 同牛市 | 买入价 × 1.015 | 买入价 × 0.95 |
| 熊市 | **做空**：出现 1S/2S/3S，信号当天按收盘价卖空 | 卖空价 × 0.985（跌 1.5%） | 卖空价 × 1.05（涨 5%） |

- 任何时候只持有一笔仓位，多空不同时持有。
- 持仓期间行情变了，不强制平仓，照常等止盈或止损。
- 做空另外扣两项成本：借券费（假设年化 0.5%，按持仓天数 ÷ 252 × 卖空金额扣除），以及持仓期间要赔给出借人的分红。
- 为了公平，做多持仓跨过除息日时，也会收到分红（`creditLongDividends = true`）。Project 1 没算这一项，所以和 Project 1 对账时要把它关掉。

### 为什么要分三组跑

v1 相对 Project 1 改了两处：熊市不再做多，改成做空。为了分清各自的效果，回测分三组：

| 组 | 熊市怎么做 | 用途 |
|---|---|---|
| P1 | 照常做多（就是 Project 1） | 基准 |
| v1a | 不开新仓 | 单看"熊市别做多"的效果 |
| v1b | 做空 1S/2S/3S | 再看"熊市做空"能多赚多少，或者多亏多少 |

v1a 比 P1 好，说明行情过滤有用；v1b 比 v1a 好，说明做空有用。只跑 v1b 的话，分不清是哪一条在起作用。

## 第一步：怎么判断行情（已确认用方案 A）

每天收盘后，只用当天及以前的数据：

```
MA200   = 最近 200 个交易日收盘价的平均
斜率    = 今天的 MA200 − 20 个交易日前的 MA200

收盘价 > MA200 且 斜率 > 0  →  牛市
收盘价 < MA200 且 斜率 < 0  →  熊市
其他情况                    →  震荡
数据不足 220 天             →  不判断，不交易
```

备选方案（以后对比，v1 不用）：

| 方案 | 思路 | 优点 | 缺点 |
|---|---|---|---|
| A. MA200 + 斜率（v1） | 价格在长期均线上方、均线向上 = 牛 | 简单，大家都用，好复现 | 反应慢，转折点要过几个月才确认 |
| B. 缠论中枢 | 两个依次抬高、互不重叠的中枢 = 上涨趋势（第 17 课） | 和 Project 1 是同一套语言 | 依赖走势段划分，噪音段会把中枢算坏 |
| C. 回撤幅度 | 离最近高点跌超 20% = 熊市 | 是市场通用的定义 | 只在事后看得清 |

## 第二步：怎么定义"回调"

v1 直接沿用 Project 1 的缠论买点，不重新发明：
- **1B**：下跌趋势里创新低，但力度变弱（底背驰）
- **2B**：1B 之后第一次回调，没跌破 1B 的低点
- **3B**：价格冲出中枢后，第一次回调没跌回中枢

备选（v2 以后再试）：从最近 N 天高点回落 X%，或者连跌 N 天。规则更简单，信号也更多。

## 执行假设

做多部分和 Project 1 一致；做空部分是镜像规则：

- 单一持仓，持仓期间不加仓。
- 做空的成交规则：
    - 开仓：卖空价 = 收盘价 × (1 − 0.05% 滑点)。
    - 止损：盘中 High 碰到止损价就触发；开盘就跳空高于止损价，按开盘价 × (1 + 滑点) 买回。
    - 止盈：盘中 Low 碰到止盈价就触发，按止盈价买回。
    - 同一天两个价都碰到，按先止损算。
- 资金：每次用 100% 可用现金，整股向下取整。
- 费用：手续费 0.05%（买卖各收一次），滑点 0.05%。
- 止盈止损都从买入后的下一个交易日开始，盘中用 High/Low 判断是否触发：
    - 开盘就跳空越过止损价，按开盘价成交。
    - 同一天既碰到止盈价又碰到止损价，按先止损算。
- 卖出当天不再买入。

## 要检验的假设

- **H1**：同样的买点，熊市里的期望收益比牛市、震荡低。
- **H2**：熊市不开新仓之后（v1a），最大回撤明显变小，总收益不降，或者只降一点。
- **H3**：熊市做空 1S/2S/3S（v1b）扣完借券费和分红后，平均每笔收益为正。
- **H4**：H1–H3 在没参与调参的样本外数据里依然成立。

## 验证方法（参数事先定好，不看结果再改）

1. **分段**：1993–2015 年用来开发和选参数；2016–2026 年只在最后跑一次，用来检验。
2. **对照组**，四组都跑：
   - P1：Project 1 原版，不过滤行情
   - v1a：熊市不开新仓
   - v1b：熊市做空 1S/2S/3S
   - 随机日期入场：方向和止盈止损跟 v1b 一样，用来检验买卖点本身有没有用
3. **参数网格事先写死**：止损 {1, 2, 3, 4, 5}% × 行情定义 {A} × 组别 {P1, v1a, v1b}。所有组合的结果都要报，不能只报最好的那组。
4. **统计**：
   - 每组都报：笔数、胜率及其 95% 置信区间、平均每笔收益、总收益、最大回撤、平均持仓天数、和随机买入的差距
   - 某类行情少于 30 笔，只描述现象，不下结论
5. **成功标准**（已确认）：在样本外（2016–2026）同时满足两条：
   - 最大回撤比 P1 至少小 20%
   - 平均每笔收益的 95% 置信区间下限不低于 0
   v1a 和 v1b 分别判断。

### 结论

- **H1（熊市里做多更差）**：部分支持。去掉熊市做多（v1a）后，最大回撤在 10 组里的 10 组都比 P1 小，样本外小了 13%–46%。
- **H2（v1a 回撤明显变小，收益不降）**：样本外 1–3% 止损时回撤小了 41%–46%，但平均每笔的区间下限都是负的；5% 止损时下限转正，但回撤只小了 13%，没到 20% 的门槛。**按事先定的标准：不通过。**
- **H3（熊市做空能赚钱）**：**不支持。** 做空 21 笔，平均每笔亏 0.38%。样本内 v1b 每一档的平均每笔都比 v1a 差，5 档里有 4 档的回撤比 P1 还大。样本外只有 4–5 笔做空，说明不了什么。
- **H4（样本外依然成立）**：没有任何一组达标。
- **随机对照**：10 次比较里，只有"止损 5%、样本外"这一次明显好过随机（3%）。比较了 10 次，碰巧出现一次 3% 并不奇怪，不能当作买卖点有效的证据。

- **三种行情一起看**：震荡 > 牛市 > 熊市做多 > 熊市做空（见上面的拆分表）。

**下一步建议**：熊市做空的思路先放下；"熊市不做"（v1a）可以保留；震荡市的回调值得单独研究。样本太少是最大的问题：样本外每组只有 26–41 笔。要扩大样本，得加别的标的（QQQ、IWM、DIA）或用分钟数据，而不是继续调参数。

## 已知局限

- "回调就买、赚一点就走"的收益结构是：经常赚一点，偶尔亏一大笔。胜率看起来很高，但只要几次大亏就能抹掉，必须看总收益和最大回撤，不能只看胜率。
- MA200 判断行情有滞后：行情转熊要过一段时间才确认，这段时间里还会继续买。
- 日线回测里，"信号当天收盘买入"假设能在收盘前几分钟估算出信号，实盘会有误差。
- 只测了 SPY 一只标的，结论不一定适用于别的股票或 ETF。
- 做空最多赚 100%（价格跌到 0），亏损却理论上没有上限：跳空高开时，亏损会远超 5%。借券费假设成固定的年化 0.5%，实际会随市场变化，极端行情时可能借不到券。
- 熊市在 33 年里只有约 1500 天，用 1S/2S/3S 做空的样本可能只有二三十笔，很可能达不到"30 笔才下结论"的门槛。
- 不连接券商、不下单，只做研究用的回测。
